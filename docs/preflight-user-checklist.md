# Preflight User Checklist

## 목적

이 문서는 실제 사용자 투입 전 매일 확인하는 운영 전 점검표다.  
체크 상태는 아래 네 가지로 기록한다.

- 정상
- 주의
- 실패
- 메모
- 확인자
- 확인시간

## 사용 방법

1. 기능을 수정하기 전에 먼저 이 표를 기준으로 실제 동작을 확인한다.
2. localStorage 단독 기능은 다른 PC에서 안 보일 수 있으므로, “공유 실패”와 “기능 실패”를 구분해 기록한다.
3. 실패가 발생하면 즉시 저장 구조를 바꾸지 말고, 어느 원본(Supabase/localStorage/fallback)에서 읽고 있는지 먼저 `docs/storage-source-of-truth.md`에서 확인한다.
